# missacc 2027年3月增长目标测算与执行规划

基于 2025-2026 年 SPU 级月度销量数据的品类增长目标测算与执行规划。目标口径：2027年3月 vs 2026年3月，收入与订单双口径；其他非裙装品类按贡献比例不变随整体增速。已决策：**按 v60 扩上新产能至 225 款/月**（v50 方案保留作对照与回退基准）。

## ⚠️ 需要特别关注的点

1. **MOB 80款/月未经验证**（v60）：超历史峰值 62，边际产出稀释风险。安全阀：0-6月新款动销率 <50% 或单款收入连续两月恶化 → 回撤 65-70/月。**这是全盘最大单点风险——MOB 承担 v60 增量的三分之一。**
2. **ED 是两版目标共同的结构性缺口**：模型推演只到 +20-29%，达标钥匙是单款产出 $330→$500 阶梯（10月$400/1月$450/3月$500），不是上新数量。**1 月阶梯不达标必须执行下调条款，不要拖。**
3. **Bride 的窗口不可逆**：8-10 月累计 110-120 款是明年 3 月的最后有效窗口（爬坡 ≥6 个月），错过无法事后弥补。**10 月检查点是硬期限。**
4. **BM 双重未验证**：上新节奏提到历史 1.8 倍 + 客单价降到 $90 后订单 +106%（履约容量）。10-11 月条件加码检查前不要提前加注。
5. **Prom 淡季上新是已证实的浪费**（动销率 2%、单款 $28）：11-1 月窗口纪律写进流程，任何人在 2-10 月提议上 Prom 新款都应被拒绝。
6. **9 月产能爬坡检查**：扩编若未到 225，按 MOB > Bride > BM 优先级保配额，砍 ED（它达标不靠数量）。
7. **模型系统性偏保守**：同一模型放去年会低估今年实际约 29pp（池成熟率与单款产出逐年改善被假设为持平）。**方向性影响：实际达成大概率优于推演，但不能以此为由放松执行。**
8. **数据依赖**：所有预警线和推演需要每月新数据驱动。**7 月起的月度 SPU 数据请按月打包提供**（格式同 2026产品业绩分析文件夹），1 月复盘需重算池成熟率 m、单款产出 p 和三层文件的全部数字。

## 关键实证结论（供回溯）

1. 2026 H1 裙装真实同比 +93%（3月 +69%），目标属降速目标；但 2027 年对比的是翻倍后的基数
2. MOB 新款边际产出 1-5 月持续上行（$520→$1,349），无饱和信号
3. Bride 爬坡 ≥6 个月（第0月 $241 → 第6月 $515 仍在涨）；MOB/Evening 爬坡仅 1-2 个月
4. 池成熟率 m（存量自然增长）：Cocktail +74% > BM +72% > FG +53% > Bride +40% > MOB +28% > Prom +10% > ED +2.8%（跑步机品类）
5. 素材缺口优先级：Prom 大码图 0.6%、ED/Cocktail 买家秀 37%/22.5%、婚纱换脸换背景 35.7%；婚纱颜色图低（4.4%）属品类特性非缺口
6. 广告 ROAS 参照（2026-03，供营销测算）：BM 5.55 / MOB 4.79 / Bride 4.45 / Prom 4.41 / ED 3.53 / CK 3.46
