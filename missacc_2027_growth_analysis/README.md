# missacc 2027年3月 +50% 增长目标测算存档

基于 2026 年 1-6 月（及 2025 年同期）SPU 级销量数据的品类增长目标测算，目标口径：2027年3月 vs 2026年3月，收入与订单双口径，其他非裙装品类按贡献比例不变统一 +50%。

## v4 最终目标摘要（日均，2026年3月按31天）

- 公司整体：日均收入 $107,222 → $161,735（+50.8%），日均订单 996 → 1,517（+52.4%）
- 分品类增速：MOB +50%、Bridesmaid +80%、Evening +65%、Cocktail +60%、Flower Girl +40%、Bride +35%、Prom +30%、其他品类统一 +50%

## 关键依据（详见对话记录）

1. 2026 H1 裙装真实同比 +93%（3月 +69%），50% 目标属于降速目标
2. MOB 新款（≤6月）边际产出 1-5 月持续上行（$520→$1,349），无饱和信号；预警线：动销率 <50% 或单款收入同比下滑且连续两月
3. Bride 新款爬坡周期约 6 个月以上（第0月 $241 → 第6月 $515 仍在涨），2027年3月目标对应上新窗口为 2026年9月前
4. Bridesmaid 3月 ROAS 5.55 全盘最高且投放占比仅 18%（投不足）；Evening ROAS 3.53 最低、投放占比 28.4% 最高
5. 素材缺口优先级：婚纱颜色图（覆盖率 4.4%）、Prom 大码图（0.6%）、Cocktail/花童买家秀（22-26%）
