# 品类驾驶舱需求

> 版本：v0.1（讨论结论整理稿）
> 驾驶舱是 L5 反馈层的品类决策视图：回答"这个品类现在该做什么决定"，而不是"这个品类的数字是多少"。
> 依赖《商品对象层需求》（等级/趋势/处置态/新品）与《换图决策需求》（判定聚合报告）。待定项统一标注 **TBD**，见第 13 节。

---

# 1. 背景与目标

## 1.1 现状

- **品类画像散在文档**：价格段、颜色、尺码、销量集中度等分析以人工文档形式存在，无固定口径、无更新节奏、无历史序列。
- **品类级决定无统一入口**：该补什么款、该下什么款、资源往哪个品类倾斜、品类质量是否恶化——这些决定分散在各处（灵鉴配置、人工报表、运营经验），互相看不见。
- **月会数据复盘依赖人工整理**：每月重复劳动，且各期口径可能漂移。

## 1.2 定位

- **决策工作台，不是看板**：报表系统回答"数字是多少"，驾驶舱回答"该做什么决定"。**每个数字必须通向一个动作出口或预警阈值**，挂不上决定的信息不收（留在报表系统）。
- **与各模块报告的分工**：驾驶舱放**摘要行 + 异常触发 + 跳转**，深度分析留在各模块自己的报告页（换图聚合报告、新品里程碑看板、处置建议审批页）。驾驶舱的角色是"路由到决定"。此分工对所有模块统一复用。
- **节奏定位**：月度品类决策视角（目标环）。周度动作节奏由各动作域自己的工作台承接（动作环）。

## 1.3 收纳原则：五类品类级决定

驾驶舱收什么内容，以"是否服务于品类级决定"为唯一标准。品类级决定共五类：

| # | 决定类型 | 回答的问题 |
|---|---|---|
| 1 | 结构决定 | 商品盘子对不对（数量、价格段、颜色、尺码的供给结构 vs 销售结构） |
| 2 | 进出决定 | 该补什么款、该下什么款 |
| 3 | 投入决定 | 资源（设计产能、营销费用、优化任务）往哪些品类/商品倾斜 |
| 4 | 新陈代谢决定 | 新品补充的节奏和质量够不够 |
| 5 | 护栏决定 | 品类有没有质量/服务问题在恶化 |

## 1.4 使用角色

主用户：管理层 + 运营负责人（当前未设"品类负责人"独立角色；若未来设立，驾驶舱即其首页——信息架构按此预留，见 **TBD** 第 1 项）。

# 2. 术语

| 术语 | 定义 |
|---|---|
| 常驻面板 | 画像区固定展示的指标面板，无论有无异常均展示，带健康状态标识 |
| 诊断结论 | 系统对各诊断维度的显式结论输出；无异常时输出"本期正常"而非空白 |
| 提示型信号 | 只展示 + 进诊断结论，不直接生成建议（阈值未校准阶段） |
| 可执行型信号 | 触发后生成带证据行的建议，进决策区待办（阈值经校准后升级） |
| 结构错配 | 某维度（价格段/颜色/尺码）的销售占比与在架占比显著失衡 |
| 集中度 | 品类销量向头部 SPU 集中的程度（三口径：Top1 / CR10 / Top10%） |
| 贡献利润 | 品类毛利 − 品类营销费用 |
| 月度快照 | 每月固定日对驾驶舱全量数据与诊断结论的归档，月会品类分册的自动生成源 |

# 3. 信息架构：一页四区

```
品类驾驶舱（单品类一页，品类列表页入口）
├─ 画像区：八个常驻面板（第 4 节）—— v1
├─ 诊断结论区：逐维度显式结论（第 5 节）—— v1
├─ 决策区：建议与待办聚合（第 6 节）—— v1
├─ 规划区：目标 vs 现状（L2 规划三件套接入后启用，v1 仅素材目标占位）
└─ 节点区：旺季拐点 / 大促 / 上新日历（L2 节点日历接入后启用，v1 留位）
```

- **v1 范围：画像区 + 诊断结论区 + 决策区**。规划区（规划表该品类的只读投影：目标/现状/差距三列）与节点区（节点实例倒计时 + 进行中节点的叠加包达成）内容由《规划三件套需求》定义，随三件套上线启用。
- **站点口径（v1 即拆站点）**：数据视图全拆——八面板支持"全站 + 各 S 级站点"切片与对比，月度快照按全站 + 各主要站点归档；**诊断与信号层 v1 统一跑全站口径**，站点切片只展示数据不出结论，待全站阈值校准稳定后按站点逐个开启（配置作用域届时加"站点覆盖"层，与品类覆盖同机制）。
- 阅读顺序即面板顺序：先结果、再结构、再过程、再护栏。

# 4. 画像区：八个常驻面板

每个面板统一具备：核心指标 + 环比（同比适用时）+ 健康状态标识（正常 / 提示 / 预警三色）+ 动作出口（跳转或建议入口）。

## 4.1 面板一：经营结果

| 指标 | 说明 |
|---|---|
| GMV / 销量 / 客单价 | 环比 + 同比双对比（品类旺季属性使同比必要） |
| 毛利额 / 毛利率 | 成本口径 = 面料 + 工费 + 物流（是否含退款损耗待定义，**TBD**） |
| 营销费用占比 | 营销费用 / GMV |
| 贡献利润 | 毛利 − 营销费用；品类间资源分配的最终依据 |

- 动作出口：毛利率恶化 → 定价/成本核查；营销占比侵蚀毛利 → 投放策略调整；与面板三联动（销售向低价段集中通常与毛利恶化互为印证）。
- 数据前置：SPU 级成本若暂不可得，v1 用品类级成本率估算，**面板上标注口径**，避免拿估算毛利做精细决定。

## 4.2 面板二：等级与集中度

- **等级分布**：9 档 SPU 数与销量占比（来自对象层主数据）+ 环比迁移（升/降档数量，来自等级迁移事件）。
- **集中度三口径**（三个口径一起算，各管一件事）：

| 指标 | 口径 | 回答的问题 |
|---|---|---|
| Top1 占比 | 最大单款销量占品类比 | 单点依赖风险——一款掉量整个品类塌 |
| CR10 | Top10 SPU 销量占比 | 头部梯队厚度 |
| Top10% 占比 | 销量前 10% SPU 的销量占比（相对口径） | 跨品类可比（大小品类用绝对 Top10 不公平） |

- **阈值来源**：不拍固定数值。初始阈值 = 品类自身近 12 个月历史分位数（如超自身 P90 触发提示），全局默认 + 品类覆盖，走统一配置机制。触发条件含**水平型**（超阈）与**趋势型**（连续 N 期上行）两类，与换图候选信号同构。
- **两端都判断**：过度集中 → 头部款护栏关注 + "第二梯队培养"建议（从 B 级挑潜力款倾斜资源）；过度分散（CR10 显著偏低且无上行）→ 缺爆款信号，检查营销聚焦。
- **分档推进**：v1 仅提示型；运行 2–3 个月以真实分布校准阈值后，"第二梯队培养"升级为可执行型出口。

## 4.3 面板三：结构三维

- 价格段 × 颜色 × 尺码，每一维展示**销售占比 vs 在架占比**双柱对比。
- 错配即结构失衡信号：某分段销售占比高而在架占比低 → 供给不足（喂决策区补款建议）；反之 → 供给过剩（结合处置态看是否该收缩）。
- 价格段错配与面板一毛利联动看。
- 数据前置：SKU 级颜色/尺码销售数据核验（**TBD** 第 3 项，本模块最大数据前置）。

## 4.4 面板四：商品数量与处置态

- 在架 SPU 总数及趋势；处置态四态分布（保持/优化/观察/下架建议中）。
- **观察态积压数**：观察池规模与停留时长分布（对象层四道防护的品类级监督视图）。
- **动销率**：近 30 天有销 SPU 占比。动销率走低 + 观察态积压走高 = 品类盘子老化的组合信号。

## 4.5 面板五：新品健康

- 新品成功率（毕业进入目标档位比例，L1 领先指标的品类切片）。
- 在保护期 SPU 数、各检查点通过率（达标/预警/触线分布）、测款失败数。
- 动作出口：跳转新品里程碑看板；成功率持续偏低 → 诊断结论区触发"上新质量"信号。

## 4.6 面板六：素材完备度与新鲜度

- **完备度**：各等级 SPU 按素材达标要求的达标率（买家秀、颜色图、大码图、风格图覆盖）——领先指标，素材先行、销量滞后。
- **目标 vs 现状**：v1 目标值来自品类配置包静态配置；L2 上线后由品类规划表接管（本面板即规划区雏形）。差距直接生成灵枢任务量预估。
- **新鲜度（换图摘要行）**：近 90 天换图判定 N 例、有效率 X%、恶化 Y 例（带环比箭头）+ 换图覆盖率（超期未换图 SPU 占比、检视队列积压）。**一行摘要，不展开五态明细**；点击跳转换图聚合报告（《换图决策需求》7.5）的本品类切片。

## 4.7 面板七：营销效率

- 访客数、转化率、单访客收入（GMV 掉了，是流量掉了还是转化掉了——诊断分叉点）。
- 品类 ROAS、花费占比（品类间营销资源分配信号）。
- 边界：**取指标不取操作**——广告组层级的出价/预算操作留在投放系统，驾驶舱只收影响品类决定的聚合指标。

## 4.8 面板八：服务与交付护栏

- 客诉率、争议率、退款率（含环比趋势）——护栏红线的品类拆解。
- 平均交付周期、延迟发货率——定制模式下交付喂客诉，供应链板块在品类视图的第一个探头。交付数据依赖供应链侧接入，**可二期**（**TBD** 第 4 项），界面位置 v1 即留出。
- 动作出口：恶化 → 质检/详情页核查/暂停放量建议；触线 → 按护栏红线机制升级。

## 4.9 核对过但确认不收的

| 项 | 理由 |
|---|---|
| 库存类指标 | 无库存模式不适用（沿用对象层决策记录） |
| 广告组操作指标、客诉工单明细 | 取指标不取操作，操作出口留在各自系统 |
| 竞品/市场外部数据 | 暂无数据源；未来"机会型信号"的可能来源 |
| 换图判定明细 | 住在换图聚合报告，驾驶舱只放摘要行（1.2 分工原则） |

# 5. 诊断结论区

**"没有问题也是诊断结果"**——区分"没看"和"看了没事"：

- 对八个面板对应的诊断维度逐项输出显式结论；全部正常时输出"本期 N 项诊断维度全部正常"，不留空白。
- 结论分三级：正常 / 提示（展示级信号）/ 预警（触发决策区建议或跳转）。
- 每条非正常结论必须带：触发规则 + 证据数据 + 动作出口链接。
- 与检视队列"检视通过也是产出"同构；结论随月度快照归档，构成品类健康历史序列。

# 6. 决策区：建议与待办聚合

| 出口 | 来源 | 形态 |
|---|---|---|
| 下架待办 | 对象层下架建议在本品类的聚合（自下而上） | 待办数 + 跳转处置建议审批页 |
| 补款建议 | 面板三结构错配信号（品类级原生，自上而下）；**带毛利约束**（低毛利段不盲目补） | 建议行：缺口维度 + 证据 + 建议方向 |
| 换图持续无效信号 | 近 90 天判定样本 ≥ N 例且有效率 < 阈值（触发型，平时不出现） | 信号行 + 跳转换图聚合报告品类切片 |
| 护栏预警 | 面板八触阈 | 预警行 + 升级机制 |
| 第二梯队培养 | 面板二集中度过高（v1 提示型，校准后升级可执行型） | 潜力款名单建议（B 级 × 上升趋势） |

- "该下架"来自 SPU 级建议聚合，"该上架（补款）"是品类级原生信号——后者只有站在品类结构层面才看得出来，这是驾驶舱不可被商品列表页替代的理由。
- 可执行型建议均为"规则出证据 + 人拍板 + 留痕"，复用换图决策工作台形态。

# 7. 月度快照

- 每月固定日（可配置）对八面板全量数据 + 诊断结论 + 决策区状态归档，按"全站 + 各主要站点"两层存（规划表站点 × 品类的现状列由站点切片喂）。
- 用途：① 月会品类分册自动生成源（替代人工整理，口径不漂移）；② 品类健康历史序列（趋势型信号的数据基础）；③ 规划区上线后"目标 vs 实际"复盘的实际值来源。
- 快照只读、不可修改；口径变更（如成本口径切换）在快照上标注版本，不回溯。

# 8. 与各层/各系统的关系

| 对象 | 关系 |
|---|---|
| 商品对象层 | 上游数据源：等级分布、迁移事件、处置态分布、趋势标签、新品里程碑（纵切看单品 → 横切看品类） |
| 换图决策系统 | 摘要行 + 触发信号 + 跳转聚合报告；不复刻判定明细 |
| 灵鉴 / 灵枢 | 素材完备度目标差距 → 任务量预估；驾驶舱不直接下发任务（决策上收、路由留守） |
| L1 指标树 | 新品成功率、素材完备度等领先指标的品类切片向上喂 |
| L2 规划三件套 | 规划区 = 规划表该品类只读投影，节点区 = 节点实例倒计时（《规划三件套需求》3.3、5.4）；月度快照站点切片喂规划表现状列；结构错配与补款建议作为上新方向输入 |
| 三会 | 月度快照 → 月会品类分册；诊断结论历史 → 季度战略环输入 |
| 站点维度 | 数据视图全拆（全站 + S 级站点切片/对比）；诊断与信号 v1 全站口径，站点级诊断待阈值校准后逐站开启 |

# 10. 数据需求与系统对接

## 10.1 数据需求清单

| 数据 | 粒度 | 现状 |
|---|---|---|
| 销量 / 流量 / 加购 / 转化 | SPU × 日（带站点字段） | 已有（对象层/换图共用） |
| 等级 / 趋势 / 处置态 / 生命周期 | SPU | 对象层主数据 |
| 颜色 / 尺码销售与在架数据 | **SKU × 日** | **需核验**（**TBD** 第 3 项） |
| 成本数据（毛利计算） | SPU 级（v1 可品类级成本率） | **需核验口径与可得性**（**TBD** 第 2 项） |
| 营销费用 / ROAS | 品类 × 日（带站点字段） | 需从投放侧聚合 |
| 客诉 / 争议 / 退款 | 品类 × 月 | 需从客服/订单侧聚合 |
| 交付周期 / 延迟发货 | 订单级 → 品类聚合 | 供应链侧接入，**可二期**（**TBD** 第 4 项） |
| 换图判定聚合 | 品类 × 90 天窗口 | 换图判定引擎已有 |

## 10.2 系统对接

- **对象层**：等级/处置态/新品数据订阅；等级迁移事件订阅。
- **换图决策系统**：聚合报告品类切片的摘要接口与跳转。
- **灵鉴**：素材达标率数据（各等级 × 素材项）。
- **投放 / 客服 / 订单系统**：聚合指标拉取（只读，取指标不取操作）。

# 12. 实现依赖顺序建议
