# 1. 背景与目标

## 1.1 现状

- **战略判断在人脑**：重点品类排序、市场容量判断、站点结构意图没有登记载体，无法被季度检验。
- **年度目标无系统对象**：明年整体与品类的 GMV/销量/利润/花费目标存在于文档，与季度规划、月度复盘没有数据链路。
- **口径分散**：GMV、转化率、毛利等口径在各模块各自定义，跨报表对不上。
- **结构意图无监控**：站点贡献占比（美国 55 / 其他 45）、大类贡献占比这类"生意形状"目标，没有现状对照面板——数字达了但形状歪了时不显形。

## 1.2 目标

- 战略从"一段话"升级为**可证伪的假设清单**，季度检验、证伪留痕。
- 年度目标成为数据对象：**年度规划**（目标/结构/策略三篇），年会锁定，季度规划表取切片。
- 指标树成为全系统**口径与责任的唯一登记处**。
- 总盘驾驶舱回答"公司整体在不在年度轨道上、生意形状对不对"。

## 1.3 设计原则

- **假设与目标分离**：假设用来被检验（季度问"还成立吗"），目标用来被达成（月度问"差多少"）；混在一起，检验和考核互相污染。两者绑定：规划差距过大先回检假设。
- **树存元数据不存数值**：指标树管口径、责任、分解关系；数值住在年度规划/季度规划表（目标端）与快照（现状端）。
- **算出来的和定出来的分开**（第三次应用）：总盘驾驶舱现状面板是算的，目标面板是年度规划的只读投影。
- **可控性原则**：指标只下放到能对它负责的层级（利润最低挂到站点、不下放品类为先例——S 级站点有专属运营与营销，能对利润负责；品类层只看毛利）。
- **护栏红线只设红线值不设改善目标**：给客诉率定改善目标会诱导动作变形。

# 3. 总体结构

```
L0 战略假设清单 ──支撑──→ 年度规划（目标/结构/策略三篇，年会锁定）
      ↑ 证伪回检                    ↓ 季度切片
      │                    季度规划表（站点×大类×品类，规划会校准后锁定）
      │                            ↓ 月度窗口
      │                    月度校准（调内容不调目标）
      │
L1 指标树（口径/责任/分解，横贯所有层）
      │
L5 总盘驾驶舱（现状面板 + 目标面板）──月度快照──→ 差距 → 目标环/战略环
```

经营对象树同步扩展一级：**总盘 → 站点 → 大类 → 品类 → SPU → SKU**。大类是静态归类（分类学），品类梯度是优先级（假设驱动的分级）——两者性质不同，都挂在品类层之上/之内。

# 4. 战略假设清单（L0）

## 4.1 假设结构

| 字段 | 说明 |
|---|---|
| 陈述 | 可证伪的判断，如"X 品类市场容量支撑我们做到 Y 规模""美国市场可维持 55% 贡献且绝对额增长" |
| 依据 | 市场容量调研、历史数据、外部信息（人工输入，系统不算，来源留痕，**TBD** 调研口径） |
| 绑定验证指标 | 从指标树引用（如该品类 GMV 增速、美国站贡献占比） |
| 检验周期 | 默认季度（战略环）；可按假设指定 |
| 状态 | 成立 / 存疑 / 证伪；状态变更留痕 |
| 影响范围 | 该假设支撑的年度规划条目（结构目标、品类梯度、品类年度目标）——证伪时知道要回调什么 |

## 4.2 假设的四类典型来源

1. **市场容量判断**：重点品类的容量与增长空间（品类梯度划分的依据）；
2. **结构判断**：站点结构（美国 55/45）、大类结构背后的市场判断；
3. **策略判断**：价格带、风格方向、新站点等经营打法层面的押注；
4. **节点押注**：对季节节点的重大押注（如"旺季 GMV 占比从 30% 提至 40%""黑五作为新站点引爆点"）——节点的日期与曲线是日历事实，住节点日历；对节点的押注是可证伪判断，登记为假设，"影响范围"指向对应的节点叠加包，证伪时顺藤回调。

## 4.3 检验流程

- 季度（战略环）系统自动出绑定指标的数据 + 趋势，人判状态；
- **证伪 → 触发年度规划回调**（经由"影响范围"字段定位回调条目），调整走变更留痕；
- **规划差距回检**：季度复盘中品类/站点差距超阈值时，材料自动附上该条目关联的假设，先问判断再问执行。

## 4.4 北极星与护栏红线登记

- **双北极星：GMV + 利润，同等重要**；切换或调权登记留痕（历史决策可追溯）。
- **营销占比为裁决器**：目标篇中有月度目标值，同时设占比上限红线——超上限的 GMV 增长不被认可为健康增长。**占比上限收编进护栏红线登记表**：性质仍是驱动指标的约束上限，但触发与升级复用红线机制——超上限走触线升级出口，而不是只在面板上显示余量（否则裁决器真要裁决的那天没有流程）。
- **护栏红线登记表**：每条红线一行、全系统唯一出处，各模块（判定引擎、驾驶舱红线面板、观察态回验）只引用不自定义。**每个环节 0–2 条**，宁缺毋滥。

| 字段 | 说明 |
|---|---|
| 指标 | 引用指标树口径：退款率、争议率、客诉率、延迟发货率、营销占比上限等 |
| 红线值 | 水平触发的判定阈值 |
| 展示要求 | 水位 + 趋势，**必须带同比/环比**——红线类重点关注变化，不只看绝对值 |
| 双触发 | **水平触发**：触线即升级（日级）；**趋势触发**：未触线但同比/环比连续恶化 N 期 → 预警（N 与恶化幅度为配置参数） |
| 第一响应环节 Owner | 触发后第一个接手处置的环节负责人（≠ 最终背责人：先接住，归因后再定责） |
| 升级路径 | 第一响应超时或无法处置后的逐级升级路线 |

初版登记（归属随双轴认领最终确定）：客服环节——客诉率、争议率；供应链环节——延迟发货率；商品环节——退款率；营销环节——营销占比上限。运营域启动后补自有触点红线候选（退订率、push 关闭率）。

# 5. 年度规划（L2 顶层）

## 5.1 三篇结构

**目标篇**：整体 GMV、利润、营销花费、营销占比 × 12 个月分解（全年最终目标 + 月度节奏，月度分解参考季节曲线加权而非均分；曲线**引用节点日历的品类同期指数曲线聚合，同一出处不另存副本**——战略层的月度目标线和规划层的节点曲线永远是同一条）。

**结构篇**：

| 结构目标 | 粒度 | 例 |
|---|---|---|
| 站点贡献占比 | 站点（S 级站点逐个 + 其他站点合并） | 美国 55%、其他合计 45% |
| 大类贡献占比 | 大类（衣服 / 鞋子+ACC） | — |
| 站点利润（预留） | 站点（S 级逐个） | 站点层利润目标行，待利润分摊口径落定后启用（TBD 8）；启用前站点层只看毛利 |
| 品类年度规划 | 站点 × 大类 × 品类：年度 GMV、销量 | 季度规划表的取数源 |

**策略篇**：品类梯度划分与策略包（见 5.3）。

## 5.2 锁定与瀑布

- **年会锁定**，版本快照；季度规划会对年度规划做"切片 + 校准"后锁定季度版本（校准幅度留痕，累计偏离过大回检假设）。
- 年中变更 = 战略环级事件：走变更审批留痕，同时必须关联到假设清单的状态变更（目标为什么改，因为哪个判断变了）。
- **加总校验（对齐链一，延长版）**：月 Σ = 季、季 Σ = 年；品类 Σ = 大类、大类 Σ = 站点、站点 Σ = 总盘。锁定时自动校验，不平不能锁。
- **假设溯源检查（锁定检查项）**：锁定时检查规划中的关键判断是否已登记为假设——结构目标、品类梯度调整、显著超历史基线的激进目标，必须关联假设清单编号；挂不上的当场补登记。对齐链二只能检验"登记过的假设"，这一步保证"该登记的判断都登记了"，否则错误判断永远没有季检对答案的那一天。

## 5.3 品类梯度（"分级配资源"第四实例）

| 要素 | 设计 |
|---|---|
| 档位 | **第一重点 / 第二重点 / 常规 / 小品类**（可配置枚举，档位数与名称可调） |
| 划分范围 | **大类内划分**（衣服大类内排梯度、鞋+ACC 内排梯度），避免跨大类直接比投入优先级 |
| 划分依据 | 市场容量判断（假设清单条目引用）+ 当前贡献占比 + 增长空间；依据留痕 |
| 刷新节奏 | **年度人定、季会可调、调整留痕**——与商品等级（月度数据自动刷新）性质不同：这是假设驱动的分级 |
| 策略包 | 每档绑定资源倾斜规则：专项池优先级、上新配额倾斜、营销预算倾斜、驾驶舱排序权重、规划会议程排序 |

消费场景：年度规划结构篇按梯度定品类目标的激进程度；产能专项池按梯度排优先级；总盘驾驶舱结构面板展示各梯度贡献占比。

# 6. 指标树（L1）

## 6.1 四类指标

| 类型 | 例子 | 性质 | 用法 |
|---|---|---|---|
| 北极星 | GMV、利润（双北极星） | 方向 | 总盘层，季会检视，切换留痕 |
| 驱动 | 流量 × 转化率 × 客单价、毛利率、营销占比（带约束上限） | 分解 | 月会拆差距（数学可分解、可归因） |
| 先行 | 新品成功率、素材完备度、上新达成率、换图有效率等 | 预警 | 先于结果变化，预判下季 |
| 护栏红线 | 退款率、争议率、客诉率、延迟发货率、营销占比上限 | 底线 | 只设红线值不设目标；双触发（水平触线日级升级 + 趋势恶化预警）；展示带同比/环比（见 4.4 护栏红线登记表） |

## 6.2 树管四样（元数据登记处，不是又一个看板）

1. **口径字典**：每个指标全系统唯一定义（GMV 含不含退款、转化率分母、毛利成本构成），下游模块只引用不自定义；已有文档中各自定义的口径（判定引擎、驾驶舱、规划表）收编至此为唯一出处。含**可加性**属性：绝对值指标必须满足**分站 Σ = 全站**（口径设计时就要保证）；比率指标登记分子分母，分站/全站值都从分子分母现算，不直接对比率做加总。
2. **责任登记**：目标四件套（口径 / 基线 / 目标值指针 / Owner）。认领双轴：**环节轴**（商品认领新品成功率、素材完备度；营销认领 ROAS、花费占比；客服认领红线第一响应…）× **对象轴**（**利润挂总盘 + 站点（站点为预留，分摊口径落定后启用，见 TBD 8）、不下放品类（品类层只看毛利）**、GMV/销量挂站点 × 大类 × 品类、动作有效率挂动作域）。可控性原则约束挂载层级。
3. **分解关系**：指标父子与归因路径（GMV 差距 → 流量/转化/客单 → 站点 × 大类 × 品类 → 驾驶舱诊断分叉）——月度动线"定位哪条腿瘸"的正式化。
4. **归因与分摊口径**（预留为主，原则：**口径先登记对，启用可以后到**）：多动作叠加在同一对象时效果怎么分摊（v1 不启用，只强制记账，见《数据底座与归因映射》第 4 节）；横向对象的成本与结果怎么摊到站点 × 品类（渠道花费最急，营销域启动时登记）；利润怎么摊到站点（总部费用/汇率/平台费，TBD 8）。

## 6.3 先行指标：全板块登记、分节奏接入

两条纪律：**每板块 1–3 个**；必须同时满足先行性（先于结果指标变化——不等于投入类指标）与可动作性（恶化时知道找谁做什么）。

| 板块 | 先行指标（初版） | v1 数据源 |
|---|---|---|
| 商品 | 新品成功率、素材完备度 | 系统自动（对象层/灵鉴） |
| 运营 | 上新达成率、换图有效率 | 系统自动（规划表/判定引擎） |
| 营销 | 花费达成进度、点击成本趋势 | **人工月度填报占位**，随板块接入自动化 |
| 供应链 | 平均交付周期、打样周期 | 人工月度填报占位 |
| 客服 | 响应时长、首次解决率 | 人工月度填报占位 |

原则：**口径先登记对，数据源可以后到**（"采集不可逆、决策可逆"的变体）。填报指标在面板上标注数据来源（自动/填报），避免混用误读。

# 7. 三条对齐链

| 链 | 机制 | 载体 |
|---|---|---|
| 一：纵向加总校验 | 月Σ季Σ年；品类Σ大类Σ站点Σ总盘；锁定时自动校验、分解依据留痕 | 年度规划 + 季度规划表 |
| 二：假设 ↔ 指标绑定 | 每条假设绑定验证指标，季检自动出数、人判状态；证伪经"影响范围"回调规划 | 假设清单 + 指标树 |
| 三：护栏红线收编 | 红线值、双触发参数与升级路径统一登记（4.4 登记表），全模块引用同一出处 | 假设清单登记 + 指标树口径 |

# 8. 总盘驾驶舱

驾驶舱模式的总盘实例：回答"整体在不在年度轨道上、生意形状对不对"。沿用品类驾驶舱设计语言：常驻面板 + 三色状态标识 + 目标只读投影 + 诊断结论显式输出（含"本期正常"）+ 月度快照（与品类快照同日）。

| 面板 | 现状侧（算出来的） | 目标侧（年度规划只读投影） |
|---|---|---|
| ① 北极星进度 | GMV / 利润月度实际与累计、营销花费与占比；**漏斗摘要行**：流量 → 加购 → 下单转化关键节点（全站口径，异常标色触发归因出口） | 年度目标月度分解线、进度差（快/慢几个点）、营销占比对上限的余量（上限触发走红线机制，见 4.4） |
| ② 结构 | 站点贡献占比、大类贡献占比、梯度贡献占比 | 结构目标 vs 现状偏离度——**结构偏离是战略级信号**：总量达标但形状歪了（如全靠单站点超额撑盘）在此显形 |
| ③ 护栏红线总览 | 退款/争议/客诉/交付时效全站水位与趋势（**带同比/环比**） | 红线值、双触发状态（触线 / 趋势预警）、升级记录 |
| ④ 先行指标总览 | 各板块先行指标（标注自动/填报来源） | 各自目标线或基准，先行预警 |

诊断出口（双北极星各有各的路）：

- **GMV 落后** → 两条路接力：对象树下钻（站点 × 大类 × 品类，沿分解关系导航至品类驾驶舱）定位"谁的问题"；因子分解（流量 × 转化率 × 客单价，漏斗摘要行异常时优先走此路）定位"什么问题"。
- **利润落后** → **因子分解路径**：利润 = 毛利率 × GMV 结构 + 费用（总部费用/汇率/平台费/营销花费，归集口径见 TBD 2）。利润最低挂到站点、不下放品类（可控性原则）：站点利润启用后（TBD 8）可下钻一跳到站点层即止，品类层不走对象树逐层下钻——毛利率恶化 → 品类毛利视图定位拖累项；费用超支 → 费用归集明细；结构劣化（低毛利品类占比升高）→ 结构面板交叉验证。
- **结构偏离** → 战略环议题。
- **红线触发**（水平触线或趋势预警）→ 升级机制，第一响应环节 Owner 接手（4.4 登记表）。
- **先行恶化** → 对应环节 Owner。
