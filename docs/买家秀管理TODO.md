## 4. 功能开发（从演示到可用）

当前页面为 mock + 内存 store 的可交互演示，刷新即重置。接入真实系统需要：

| 状态 | 项 | 说明 |
|---|---|---|
| ⬜ | 接口层 | 抽 `src/api/`，替换 store 中的内存操作 |
| ⬜ | 在架 SPU / 首图 / 销量数据源 | 质检图库列表依赖商品主数据与近 30 天销量 |
| ⬜ | 灵鉴对接 | 接收主任务；回传节点：待领取 / 制作中 / 待审核 / 已推送 / 废弃 |
| ⬜ | CMS 推送 | 待推送后自动整体推送；子任务编号幂等；失败可重推 |
| ⬜ | nano banana 生图任务 | 异步回调；生成次数、版本历史落库 |
| ⬜ | 文件上传 | 质检图上传、上传覆盖结果图、素材批量上传 |
| ⬜ | 权限接入 | 用真实登录角色替换 `RoleContext` 手动切换 |
