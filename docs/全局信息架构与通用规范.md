# 1. 全局导航与页面地图

## 1.1 一级导航（六个板块）

```
经营决策系统
├─ 总盘         总盘驾驶舱
├─ 规划         品类规划表 · 节点日历 · 预案库 · 产能账
├─ 品类         品类列表（按大类分组 · 梯度排序 · 站点过滤）→ 品类驾驶舱 · 月度快照归档
├─ 工作台       个人待办中心 · 换图工作台（候选/进行中/判定）· 处置建议审批 · 新品里程碑看板 · 商品对象总览
├─ 资产         风格库计分卡 · 预案库 · 战略假设清单 · 指标树管理 · 判定报告
└─ 配置中心     统一配置页，按模块分区（换图 / 对象层 / 驾驶舱 / 规划 / 战略）
```

- 预案库同时出现在"规划"（编排语境）与"资产"（治理语境），同一页面两个入口。
- **各角色默认首页**：管理层 → 总盘驾驶舱；站点 Owner → 品类列表（按其站点过滤）；运营 → 个人待办中心；风格库负责人 → 风格库计分卡。

# 3. 通用组件规范（四个，一次定义、处处引用）

## 3.1 建议卡片

所有"规则出证据 + 人拍板"场景的统一形态：

| 区块 | 内容 |
|---|---|
| 对象标识 | SPU / 品类 / 节点（点击跳 SPU 360 或对应详情） |
| 来源标签 | 触发来源（表现驱动 / 判定驱动 / 治理驱动 / 事件驱动 / 人工提报 / 结构信号…） |
| 证据行 | 触发规则 + 关键数据（等级、趋势、指标值、对比基准）；数据可展开 |
| 建议内容 | 建议动作 + 参数（如目标风格 + 置信度、下架、补款方向） |
| 操作 | 批准 / 改选 / 驳回（必填理由）；支持批量 |
| 留痕 | 自动生成留痕记录条（3.3） |

复用场景：换图候选审批、处置建议审批（下架/迁移/唤醒）、补款建议、节点待确认、风格库迁移待批、回滚与收投放待批。

## 3.2 目标 vs 现状面板

| 要素 | 规范 |
|---|---|
| 目标侧 | 只读投影，标注来源版本（年度规划 vX / 季度锁定版 vX / 叠加包 vX） |
| 现状侧 | 标注数据截至日期与口径（引用指标树口径字典） |
| 差距 | 差值 + 达成率 + 红黄绿三色（阈值可配）+ 环比箭头 |
| 数据来源标注 | 自动 / 人工填报，混排时逐项标注 |

复用场景：驾驶舱规划区、总盘驾驶舱四面板、素材目标、新品检查点、叠加包达成。

## 3.3 留痕记录条

所有决策对象（处置态、规划版本、配置、假设状态、节点确认、审批操作）的统一留痕格式：**操作人 / 时间 / 操作类型 / 依据（规则引用或理由文本）/ 前值 → 后值 / 关联版本号**。按对象聚合成历史时间线，SPU 360 与各详情页展示。

## 3.4 诊断结论行

| 要素 | 规范 |
|---|---|
| 维度 + 状态 | 正常 / 提示 / 预警三级 |
| 无异常显式输出 | "本期 N 项诊断维度全部正常"，不留空白 |
| 非正常结论必带 | 触发规则 + 证据数据链接 + 动作出口链接 |
| 归档 | 随月度快照，构成健康历史序列 |

复用场景：品类驾驶舱诊断区、总盘驾驶舱诊断、检视队列产出、观察态检视记录。

# 4. 通知与预警送达机制

原则：**预警如果到不了人，等于不存在**。按信号节奏分三级送达：

| 级别 | 信号 | 送达方式 |
|---|---|---|
| 日级（等不起） | 护栏触线、节点触发链延误 | 个人待办中心**置顶红条** + 即时渠道推送（邮件 / IM，渠道选型 **TBD**） |
| 周度 | 处置建议跑批、换图候选、检视队列到期 | 个人待办中心待办项（按角色路由：下架终审 → 运营负责人，候选审批 → 运营…） |
| 月度 | 快照生成、诊断结论、产能对账、填报提醒 | 待办中心提醒项 + 归档页 |

待办路由规则跟随权限矩阵：谁有"批"权限，建议就进谁的待办。

# 7. 口径修订记录（四处缝隙，已同步修订各文档）

1. **等级消费口径**：决策类消费（动作候选、处置态、判定）用**全局等级**；资源排队类消费（常规池站点内任务优先级）用**分站等级**；素材达标要求随全局等级（主图素材全站共用）。详见《商品对象层需求》4.5。
2. **差距粒度 vs 诊断粒度**：规划差距（红黄绿）是机械计算（目标 − 现状，无需阈值校准），可按站点 × 品类粒度展示；受"全站先行"限制的只是需要阈值校准的诊断信号。详见《品类驾驶舱需求》第 3 节。
3. **新品期与换图候选**：新品期 SPU 不进换图候选（无处置态即被前置闸排除，为有意设计）；新品图片动作走检查点预警出口的"首图测试"（流程 **TBD**）。详见《商品对象层需求》7.1、《换图决策需求》4.7。
4. **配置中心统一**：全系统一个配置中心页面，按模块分区（换图 / 对象层 / 驾驶舱 / 规划 / 战略）；各文档原"配置页"表述已改为指向对应分区。作用域、版本化、分期、校准闭环机制不变（《换图决策需求》第 10 节）。
