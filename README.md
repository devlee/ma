# 爆款健康度分析(衣服品类)

基于 Top20 / Top50 / Top100 款销量占比数据,对 9 个衣服子品类的爆款结构做健康度评估。

- `index.html` — 交互式看板:健康度总分排行、头/腰/尾销量结构、铺款效率散点、四维得分明细、分品类诊断与建议。直接用浏览器打开即可(ECharts 已本地化,无需联网)。
- `爆款健康度分析报告.md` — 完整分析报告:评分模型、分品类诊断、行动优先级。
- `assets/echarts.min.js` — 本地化的 Apache ECharts 5.5.1。

## 评分模型

综合得分 = 爆款强度 × 30% + 集中度安全 × 25% + 腰部厚度 × 25% + 单款效率 × 20%(满分 100)

等级:≥85 健康,70~85 亚健康,55~70 关注,<55 预警。
